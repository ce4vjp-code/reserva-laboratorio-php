Documentación Técnica

Arquitectura y modelo de datos del sistema de reserva de laboratorios.

§ 01

Base de Datos

El esquema principal utiliza la tabla laboratorio_reservas. InnoDB MySQL/MariaDB.

Columna Tipo y Restricciones
id INT AUTO_INCREMENT PRIMARY KEY
fecha DATE NOT NULL
dia_semana INT NOT NULL (1=Lunes, 5=Viernes)
bloque_id INT NOT NULL (1-9)
usuario_id INT NOT NULL
estado ENUM('reservado', 'confirmado', 'disponible')
⚡
Restricción Única: La combinación de UNIQUE KEY(fecha, bloque_id) previene reservas superpuestas a nivel de base de datos.

Se implementa en PHP nativo y PDO.

PDO
Capa de Acceso a Datos

Security
JSON
Intercambio de Datos
